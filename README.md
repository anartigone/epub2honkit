# EPUB2Honkit
This script converts EPUB into HonKit project right at current directory.
Note: There is fixed path exclusively for my other HonKit project in the root SUMMARY.md. Change it as needed. Instructions below are generated by Llama3.1.

**Introduction**

This is a Python script that converts EPUB files to Honkit projects. Honkit is a tool for creating and managing documentation, and this script makes it easy to convert EPUB files into a format that can be used with Honkit.

**Installation**

To use this script, you'll need to have Python installed on your computer. You can download the latest version of Python from the official Python website.

Once you have Python installed, you can install the required dependencies by running the following command in your terminal:

```bash
pip install ebooklib beautifulsoup4
```

**Usage**

To use this script, simply run the following command in your terminal:

```bash
python epub_to_honkit.py
```

You will be prompted to enter the path to the EPUB file you want to convert. Enter the path, and the script will create a new Honkit project in the same directory.

**Customization**

You can customize the output of the script by modifying the `epub_to_honkit.py` file. For example, you can change the directory structure of the output project by modifying the `project_dir` variable.

You can also customize the content of the output project by modifying the `SUMMARY.md` file. This file is used to generate the table of contents for the project, and you can add or remove sections as needed.

**Troubleshooting**

If you encounter any issues while using this script, please check the following:

* Make sure you have the latest version of Python installed.
* Make sure you have the required dependencies installed.
* Make sure the EPUB file you are trying to convert is valid and not corrupted.

If you are still having issues, please open an issue on this repository and I will do my best to help you.
